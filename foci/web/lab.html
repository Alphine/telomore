Browser lab: analyse images without uploading them

Drop a nuclear stain and a punctate marker (for example 53BP1 or gamma-H2AX), as one multi-channel file or as two files per field, or a whole batch. Files are read and analysed inside your browser; nothing is sent anywhere.

Read this first.
  • This is a classical counter and exploratory. It is not validated against manual counts (Experiments L and L2 in the project record). Tune the parameters on your own positive and negative controls before trusting a number.
  • 53BP1 and gamma-H2AX foci mark DNA double-strand breaks anywhere in the genome; they are not telomere-specific.
  • Your files never leave your machine. This page is not allowed to make network requests: a Content-Security-Policy in the page header blocks them, and a test checks that the code contains none. Only fonts and the page's own scripts are loaded.
  • Large images need a lot of memory (16 megapixels per channel is the limit). If a tab runs out of memory, use smaller images or a pool size of 1.

2. Pair files and assign channels

Files whose names contain a nuclei word and a foci word are paired when the rest of the name matches. You can edit the words (comma-separated), pick a preset, or assign every channel by hand below. A single multi-channel file becomes one set by itself.

Label conditions in bulk (optional; e.g. every set whose name contains “ctrl” is “control”)

3. Parameters and engine

Checking the analysis engine…

v1 counts touching nuclei by area. v2 separates them (distance-transform watershed, CPU only). Only the nucleus step differs; the foci counting step is identical and remains unvalidated, so a better nucleus count is not evidence of more accurate foci counts.

Each worker holds one image pair in memory while it runs; use 1 for very large images.
