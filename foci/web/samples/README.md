# Foci Lab sample images

Image Data Resource, study idr0010 (https://idr.openmicroscopy.org/webclient/?show=screen-1351). Doil et al., Cell 2009, doi:10.1016/j.cell.2008.12.041. Licence CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Images re-rendered by the IDR as 8-bit greyscale PNGs (linear window from the channel minimum to the curators' display maximum); no other change.

Rebuild: `python scripts/fetch_foci_samples.py` (or the GitHub Action `Refresh Foci Lab samples`).
Use: download a DNA + 53BP1 pair and drop both into Browser lab (`lab.html`).
